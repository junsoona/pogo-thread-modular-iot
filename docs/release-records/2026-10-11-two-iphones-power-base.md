# 2026-10-11 두 iPhone의 Power Base 관리 실물 시험

이 기록은 사용자가 제공한 설치·Linux 명령 출력, 화면과 시험 결과 보고에 근거한다. 기록 작성자가 보드나 Linux에서 직접 시험한 결과가 아니다. 대상은 iPhone 13 mini, iPhone 16 Pro Max, 같은 OTBR/허브와 시험용 Power Base 및 SGP41·PMS5003 두 모듈이다. 실제 보드·허브 식별값과 원본 로그는 공개하지 않는다.

- Linux bridge 0.5.0: `590e2a11d2cb+dirty.dbbfd0450300`, 소스 지문 `dbbfd045030040163ae270ba7ef845f94d7bf5cfaf91a7d6c16361047b44e04c`. 사용자 Linux에서 prep7 묶음의 전체 검증과 배포 완료 보고를 확인했다. Linux 실행 파일과 manifest의 해시는 이번 공개 기록에 새로 검증해 옮기지 않았다.
- Power Base 0.3.0, module 0.1.1, RCP 0.1.0은 이번 앱·허브 설치에서 변경하지 않았다. 이 기록은 세 보드의 실제 이미지 식별을 새로 검증한 것이 아니다.
- Git 보존 직전 공식 도구로 현재 앱 소스·설치 후보·manifest의 일치를 확인했고, 현재 허브 소스 지문도 위 값과 일치했다. 공개 문서 정리 후에도 두 소스 지문이 그대로인지 확인한다.
- 시험한 후보는 development 빌드다. 커밋 후 HEAD가 바뀌어도 과거 후보의 build id와 manifest는 수정하지 않는다. 이 두 지문으로 해당 후보와 보존한 소스의 연결을 확인한다.

## 사용자 실물 결과 — 통과

- 두 iPhone 설치와 표시 버전 확인, Base·두 센서 표시와 값 갱신, 설정 공유.
- 전경 관찰, 백그라운드 1분·20분 복귀, Wi-Fi 복귀, 허브 재시작 뒤 양쪽 앱 복귀. 백그라운드 관찰 중 삭제·목록 제거를 한 것은 아니다.
- 삭제·재등록 4회, 두 센서 복귀와 양쪽 화면 유지. 삭제 확인창·취소·동시 삭제·다른 탭에서 완료.
- K2(응답을 놓친 삭제 요청), K3(예전 요청과 새 등록 보호) 모두 사용자 통과 보고. K3는 두 iPhone의 역할을 바꿔 양방향 확인.
- 오프라인 Base의 허브 목록 제거, 전원 복귀 뒤 5분간 재등장 없음, 앱·허브 재시작 뒤에도 없음.
- 로컬 초기화 후 같은 허브 재등록: 두 센서 복귀, 이전 방 해제, 삭제 버튼 정상.
- 삭제 대기 중 목록 제거와 재시작 후 정리: 취소 안내, 대기 카드 제거, 방 해제, 재등록 유지.
- 두 iPhone에서 동시 목록 제거: 양쪽 Base와 센서가 사라짐. 제공된 허브 로그에 목록 제거 1회 확인. 로그의 방 정리 대상 0개를 센서 수로 해석하지 않는다.
- 다른 iPhone의 목록 제거 후 열어 둔 확인창 자동 닫힘, 재등록 정상.

## 통과로 세지 않은 범위

- 목록 제거의 응답 유실: Wi-Fi를 끄기 전에 요청이 전달돼 원하는 상태를 재현하지 못했다. 통과·실패로 세지 않는다.
- 삭제·목록 제거를 통째로 놓친 앱의 15분 이상 뒤 복귀는 사용자 요청으로 실물 시험에서 제외했다. 기존 자동 검사와 구분한다.
- 두 Base 사이 모듈 이동·방 보존, 두 허브 사이 이동, Watch·위젯 반영, 만들기 어려운 삭제 미확인 상태는 이번 핵심 시험 완료에 포함하지 않는다.
- P4의 간헐적 PMS 복구 지연은 보류했다. 해결됐다고 표현하지 않는다.
- 실물에서는 주기 GET이 켜져 있었다. 화면 갱신 통과를 SSE 단독 전달의 증명이나 메모리·지연 측정으로 확대하지 않는다. SSE 단독 증거는 기존 Mac·시뮬레이터 검사다.

## 종료와 원본 보존

두 iPhone과 위 시험 구성의 핵심 삭제·화면 갱신·목록 제거 시험 묶음을 종료했다. 프로젝트의 모든 조건을 실물 검증했다는 뜻은 아니다. 프로파일 갱신은 사용자가 별도 진행한다. 기존 후보, 원본 결과·로그·백업은 저장소 밖에 그대로 보존하며 이번 GitHub push에 포함하지 않는다.

기존 host·시뮬레이터 검사는 각 저장소의 validation-status 문서에 작성 당시 상태로 남긴다. 본 기록은 그 뒤의 사용자 실물 결과다. 문서 정리와 Git 보존을 위해 기능 시험·설치·flash·Linux 배포를 다시 수행하지 않았다. 제품 버전도 올리지 않았다.
